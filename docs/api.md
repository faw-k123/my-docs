# API 参考

> 说明：下面是模拟接口文档，没有真实后端服务，仅用来完成本次MkDocs作业，展示代码块、表格的渲染效果。

## 查询文档列表接口

- 请求方法：GET
- 请求路径：/api/docs
- 功能：获取网站全部文档条目列表

### 请求参数
无

### 返回示例（JSON代码块）
```json
{
  "items": [
    {"id": 1, "title": "首页", "path": "index.md"},
    {"id": 2, "title": "关于本项目", "path": "about.md"},
    {"id": 3, "title": "使用指南", "path": "guide.md"}
  ],
  "total": 3
}
```

### 返回字段说明表
| 字段名 | 数据类型 | 说明 |
| ---- | ---- | ---- |
| items | 数组 | 文档条目数组 |
| id | 整数 | 文档唯一编号 |
| title | 字符串 | 文档标题 |
| path | 字符串 | 文档源文件路径 |
| total | 整数 | 文档总数量 |

## 获取单个文档详情接口
- 请求方法：GET
- 请求路径：/api/docs/{id}
- 路径参数：id 文档编号

### 示例请求
```
GET /api/docs/2
```

### 响应示例
```json
{
  "id": 2,
  "title": "关于本项目",
  "content": "本项目使用MkDocs和GitHub Actions搭建静态文档网站。"
}
```
