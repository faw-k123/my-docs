# 关于本项目

## 项目目标
本次实践项目目标：基于MkDocs编写Markdown文档，配置GitHub Actions流水线，实现代码推送后自动构建静态网页并部署到GitHub Pages，理解静态站点自动化发布完整流程。

## 技术组成

| 工具 | 作用 |
| --- | --- |
| Markdown | 编写文档内容，轻量化标记语言 |
| MkDocs Material | MkDocs的现代化主题，将md文档构建成美观静态网站 |
| GitHub Actions | CI/CD流水线，自动执行安装依赖、构建网站、部署 |
| GitHub Pages | GitHub提供静态网页托管服务，对外公开访问网站 |

## 实践收获
通过本次实践，掌握仓库创建、Git提交推送、MkDocs配置，学会阅读Actions运行日志排查部署问题，理解源码、构建产物、流水线、托管网站之间的关系。
